# RAG System Logging & Testing Guide

## Overview

The RAG (Retrieval-Augmented Generation) system has been enhanced with:
1. **Comprehensive logging** at every step
2. **LLM-synthesized hints** using Claude Haiku for natural responses
3. **Detailed visibility** into ChromaDB queries and results

---

## What Changed

### 1. **New RAG Synthesizer Service** (`app/services/rag_synthesizer.py`)
- Uses Claude 3.5 Haiku to synthesize natural, conversational hints
- Takes top-k ChromaDB results + original question
- Generates 2-3 sentence hints that sound like advice from a colleague
- Falls back to raw chunk if synthesis fails

### 2. **Enhanced VectorService Logging** (`app/services/vector_service.py`)
- Logs ChromaDB collection size before each query
- Warns if collection is empty (no embedded documents)
- Logs each retrieved result with similarity score and source
- Shows text previews of matched chunks

### 3. **Enhanced RAGClassifier Logging** (`app/services/rag_classifier.py`)
- Logs every question being classified
- Shows Claude's classification response
- Logs decision (PRODUCT vs CONVERSATIONAL) with timing
- Helps debug why questions are/aren't triggering RAG

### 4. **Enhanced ChromaDB Client Logging** (`app/database/chroma_client.py`)
- Shows collection stats on initialization
- Displays embedding model being used (all-MiniLM-L6-v2)
- Warns if collection is empty
- Shows vector count

### 5. **Updated Webhook RAG Pipeline** (`app/api/routes/sessions.py`)
- Added step-by-step logging with emojis for easy scanning
- Integrated RAG synthesizer
- Shows complete hint content when saved
- Better error handling with detailed logs

## How RAG Triggering Works

### Step-by-Step Flow:

1. **VAPI sends webhook**
   - POST `/api/sessions/vapi/webhook`
   - Event type: `"transcript"`
   - Payload includes `role` and `transcript` text

2. **Filter for AI messages**
   - Only process when `role == "assistant"`
   - User messages are ignored

3. **RAG Pipeline (4 steps):**

   **Step 1: Classification** (RAGClassifier)
   ```
   🤔 RAG Classifier: Analyzing question...
   ✅ PRODUCT question detected → Triggering RAG pipeline
   ```
   - Uses Claude Haiku to classify: PRODUCT vs CONVERSATIONAL
   - Logs classification time (~0.5-1s)

   **Step 2: ChromaDB Query** (VectorService)
   ```
   🔍 ChromaDB Query: 'What's the pricing?' | Collection size: 45 vectors
   📊 ChromaDB returned 3 result(s)
     Result #1: Pricing | Similarity: 0.872 | Text preview: '...'
   ```
   - Queries ChromaDB for relevant chunks
   - Logs collection size, similarity scores, sources

   **Step 3: LLM Synthesis** (RAGSynthesizer)
   ```
   🔍 RAG Synthesis: Synthesizing response using 3 chunks
   ✅ Generated hint in 0.83s: 'We offer three pricing tiers...'
   ```
   - Passes chunks + question to Claude Haiku
   - Generates natural, conversational hint
   - Falls back to raw chunk if fails

   **Step 4: Save to Database**
   ```
   ✅ RAG Pipeline Complete! Hint saved:
      Session: abc12345...
      Question: 'What's your pricing model?'
      Source: Pricing
      Relevance: 0.872
      Hint: 'We offer three pricing tiers starting at $29/month...'
   ```

4. **Frontend Polling**
   - `useHints` hook polls `/sessions/{id}/hints` every 2 seconds
   - Retrieves new undelivered hints
   - Marks as delivered after fetching

5. **Display in HintPanel**
   - Shows hints in practice session UI
   - User can toggle visibility

## How to Test

### 1. **Check Backend Logs**

Start your backend with logging visible:

```bash
cd backend
python -m uvicorn app.main:app --reload --log-level info
```

Look for these log patterns:

**On startup:**
```
📚 ChromaDB Collection Ready:
   Name: product_knowledge
   Vectors: 45
   Embedding Model: all-MiniLM-L6-v2
   Similarity Metric: cosine
```

**During a call (when AI asks a question):**
```
🎤 AI Transcript Received: 'What's your pricing?' (length: 19 chars)
📋 Session Found: abc12345... | Product: xyz67890...
🔍 RAG Step 1: Classifying question...
🤔 RAG Classifier: Analyzing question: 'What's your pricing?'
✅ RAG Classifier: PRODUCT question detected → Triggering RAG pipeline (took 0.67s)
```

### 2. **Verify ChromaDB Has Data**

Check if your product has embedded documents:

```bash
# In Python console
from app.database.chroma_client import get_product_collection

collection = get_product_collection()
print(f"Total vectors: {collection.count()}")

# Check specific product
results = collection.get(where={"product_id": "your-product-uuid"})
print(f"Vectors for product: {len(results['ids'])}")
```

If count is 0, you need to upload documents:
- Go to product page in frontend
- Upload PDF/TXT documents
- Check backend logs for embedding confirmation

### 3. **Test Classification**

To verify the classifier is working, watch logs during a call:

**Product questions (should trigger RAG):**
- "What's your pricing?"
- "Do you integrate with Salesforce?"
- "What features are included?"
- "How does your product compare to competitors?"

**Conversational questions (should skip RAG):**
- "How are you doing today?"
- "Can I ask you a few questions?"
- "Tell me about your company"
- "What challenges are you facing?"

### 4. **Check Database**

Verify hints are being saved:

```sql
-- In Supabase SQL editor
SELECT
    sh.question,
    sh.hint_text,
    sh.source_name,
    sh.relevance_score,
    sh.delivered,
    sh.created_at
FROM session_hints sh
WHERE session_id = 'your-session-id'
ORDER BY created_at DESC;
```

1. Start a practice session with a product that has uploaded documents

   - `[useHints] Received N new hint(s)` logs
   - Network requests to `/api/sessions/{id}/hints`

## Troubleshooting

### No hints appearing?

**Check 1: ChromaDB has data**
```
⚠️ ChromaDB collection is EMPTY - no embedded documents available
```
→ Upload documents via product page

**Check 2: Product is linked to session**
```
ℹ️ No product_id for session abc12345... - skipping RAG
```
→ Create session with a product_id

**Check 3: Questions are being classified as PRODUCT**
```
💬 RAG Classifier: CONVERSATIONAL question → Skipping RAG
```
→ Ask more specific product questions

**Check 4: ChromaDB finding results**
```
⚠️ No results found for product xyz67890... - product may not have embedded documents
```
→ Verify product_id matches embedded documents

**Check 5: API keys configured**
```
Classifier error: Anthropic API key not configured
```
→ Check `.env` file has `ANTHROPIC_API_KEY`

### Hints appearing but not natural?

Check if synthesis is working:
```
✅ RAG Synthesis: Generated hint in 0.83s: '...'
```

If you see:
```
⚠️ Synthesis failed - falling back to raw chunk text
```
→ Check Anthropic API key and quota

## Performance Notes

**Typical Timings:**
- Classification: 0.5-1.0s (Claude Haiku)
- ChromaDB Query: 0.05-0.2s (local)
- Synthesis: 0.8-1.2s (Claude Haiku)
- **Total**: ~1.5-2.5s from question to hint saved

**Cost per hint:**
- Classification: ~$0.0001 (50 tokens)
- Synthesis: ~$0.0005 (150 tokens)
- **Total**: ~$0.0006 per hint (very cheap!)
